# 💫 About Me:
I’m an AWS Certified Solutions Architect – Associate with a Master’s in Data Science and a background that taught me to work carefully when the stakes are high.
Before moving into cloud and data, I spent more than ten years in hospitality industry where accuracy and discretion mattered every day. I often under tight deadlines, handled confidential information for high-profile clients. That habit of getting the details right is something I now bring to every infrastructure and data problem I work on.
On the technical side, I work with Python (Pandas, NumPy, Scikit-learn) and SQL (T-SQL, PostgreSQL, IBM DB2). My AWS experience covers a wide range of services, including EC2, S3, RDS, DynamoDB, Lambda, Fargate, VPC, API Gateway, SQS, SNS, Route 53, EMR, Cognito, and CloudWatch, along with core networking and scaling tools like ELB, Auto Scaling, and Direct Connect.
I’m continuing to build my skills through hands-on projects, designing solutions that are reliable, secure, and cost-conscious.
I’m open to Solutions Architect, Cloud Support, and Cloud Engineer roles where I can combine my data science training with cloud architecture and keep growing as an engineer. I am trying to get an AWS Data Engineer Associate certified next.

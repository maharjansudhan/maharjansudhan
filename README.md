# 💫 About Me:
I'm building a career as an AWS Solutions Architect, combining a Master's in Data Science with hands-on AWS certification and a background of high-precision, high-pressure execution.<br> <br>I hold the AWS Certified Cloud Practitioner credential and am currently working toward AWS Solutions Architect – Associate. My technical foundation includes Python (Pandas, NumPy, Scikit-learn), SQL (T-SQL, PostgreSQL, IBM DB2), and core AWS services including EC2, S3, RDS, DynamoDB, Lambda, CloudWatch, Fargate, SQS, SNS, Route 53, EMR, Cognito, Amplify, API Gateway, ELB, VPC, Direct Connect, ASG, and AWS networking fundamentals.<br> <br>Before transitioning into cloud and data, I spent over a decade in high-stakes service environments where accuracy and discretion were non-negotiable — including maintaining zero data-entry errors across 30+ daily records under time pressure, and safeguarding confidential information for high-profile clients. That same precision now shows up in how I approach infrastructure and data problems.<br> <br>Currently deepening my AWS architecture skills through hands-on projects and certification study. Open to Solutions Architect, Cloud Support, or entry-level Cloud Engineer opportunities.
